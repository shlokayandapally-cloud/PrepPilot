# PrepPilot — Interview Practice Dashboard

A beginner-friendly, single-file website prototype built with HTML, CSS and JavaScript.

## Features
- Dashboard with practice stats and score chart
- Searchable question bank with categories
- Quick question practice and a four-question mock interview
- Demo score and feedback
- Progress history and personalized tips
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and click **New repository**.
2. Name it `preppilot-interview-dashboard`.
3. Set it to **Public**, then create the repository.
4. Click **Add file → Upload files**.
5. Upload `index.html` and `README.md` from this folder.
6. Click **Commit changes**.
7. Open **Settings → Pages**.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Select branch **main** and folder **/(root)**, then click **Save**.
10. Wait a minute and refresh the Pages section. Open the published URL shown there.

## Prototype limitations
This is a demo, not a production AI interview evaluator. The score uses answer completion and length as simple heuristics; it does not judge factual accuracy or speaking quality. Demo history is kept in page memory and may reset on refresh. No login, backend, or personal-data collection is implemented.
